# 실제로 밟은 함정

1. **가게 외관 사진** — 생성하면 빈 간판·어색한 글자가 나와 AI 티가 난다. 내부·진열대·손·음식 클로즈업으로 대체.
2. **음식 이름 오해** — "로제 떡볶이"를 장미로 그린다. 조리법으로 풀어 쓴다("cream chili sauce").
3. **층 분해 이미지** — 버거처럼 층을 따로 움직이려면 단색(초록) 배경으로 생성 → PIL로 층별 컷아웃. 투명 배경을 요청하면 가짜 체크무늬가 그려진다.
4. **CSS 우선순위 퇴행** — 수정 중 뒤쪽 규칙이 앞의 모바일 규칙을 덮어 합계 바가 콘텐츠를 가렸다. 고정 하단 바가 있으면 본문에 같은 높이 `padding-bottom`, 수정 후 전 폭 재캡처.
5. **스티키 탭 활성 표시** — IntersectionObserver 기준선을 탭 바 바로 아래로(`rootMargin:-<탭높이>px 0px -70% 0px`). 기본값이면 탭이 한 칸씩 늦게 바뀐다.
6. **탭 클릭 스크롤** — `scroll-margin-top`을 헤더+탭 높이로 주지 않으면 분류 제목이 탭 밑에 숨는다.
7. **품절 표시** — 색만 흐리게 하면 구분이 안 된다(색각·야외 화면). 취소선 + "품절" 글자.
8. **시트 스크롤 관통** — 시트가 열렸을 때 body 스크롤 잠금, 시트 안은 `overscroll-behavior:contain`.
9. **검증 글꼴** — 캡처 전 `document.fonts.ready`. 대체 글꼴 화면으로 판단하면 검토가 무효.
10. **가상 가게 도메인** — `<업종>-menu.vercel.app`은 이미 남이 쓰는 경우가 많다(bakery-menu, burger-menu) → 배포 후 title 확인, `vercel domains add <새이름>.vercel.app <project>`.
11. **설계 문서 공개** — PRODUCT.md·DESIGN.md·작업 폴더를 `.vercelignore`에 넣지 않으면 그대로 공개된다.
12. **마감 리뷰** — 완성 후 별도 검토(에이전트든 사람이든)를 한 번 돌리면 CSS 퇴행·가림 같은 실제 결함이 잡힌다. 자기 눈만 믿지 않는다.
