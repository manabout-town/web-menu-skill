# web-menu — 가게 메뉴판

유저가 확정한 기준:
- **메뉴는 데이터 한 곳**에서 그린다. 사장님이 고칠 곳은 배열 하나.
- **가게마다 주문 도구가 다르다.** 목록만 있는 메뉴판은 종이 메뉴판과 다를 게 없다.
- **음식·공간은 실사 사진.** 가상 가게 외관은 빈 간판 때문에 AI 티가 난다 → 내부·진열·손 클로즈업.

예시 코드: `assets/example/` = 을지로 진 바 「Still No.7」(다크모드 + 라임 1색). 증류 방울 ABV 0→47% 로더 → 핀 「한 잔의 구조」 5컷 → 이번 주 한정(남은 잔 수) → 분류 탭·검색·취향 태그·품절 숨기기 → 샷/보틀 2단 가격·브랜드 하위 라인업 → 상세 시트(설명·태그·비슷한 술). 사진 포함, 바로 열린다.

## 1. 네 가지 결정 (코드 전에)

`references/catalog.md` 표를 먼저 본다. 새 가게는 네 칸이 기존 줄과 겹치지 않게.

| 결정 | 질문 | 예 (한우) |
|---|---|---|
| 스타일 1개 | 이 가게에 기대하는 인상은? | 다크모드 — 경매장 넘김판 |
| 진입 | 손님이 가게에 들어서는 순간은? | 경매판 글자가 촤르륵 넘어감 |
| 주문 도구 | 이 메뉴에서 손님이 가장 고민하는 것은? | "몇 명이면 몇 인분?" → 인원 계산기 + 부위 지도 |
| 사진 장면 | 무엇을 보여야 먹고 싶어지나? | 마블링 클로즈업, 불판 위 |

유저에게 짧게 알리고 진행한다.

## 2. 데이터 설계

```js
const MENU = [
  {id:"signature", ko:"시그니처", en:"Signature", note:"…", items:[
    {id:"s1", ko:"을지로 G&T", price:"1.6", img:"sig-1", sig:true, star:1,
     tags:["허브","시트러스"], desc:"…", sim:["g-hendricks"], out:false},
  ]},
];
```
- 분류 = 배열 순서 = 탭 순서. 항목 필드는 가게에 맞게: `price` 하나 / `shot`·`bottle` 2단 / `kids`(하위 라인업) / `left`·`total`(한정 수량) / `kcal`·`spicy`·`allergy`.
- 가격 표기는 가게 문화대로 하나만: 원 단위 전체(식당) 또는 만원 축약(바: `1.4` = 14,000원 — 상단에 한 번 설명).
- **품절** `out:true` → 취소선 + "품절" 글자(색만으로 표시하지 않음) + "품절 숨기기" 토글.
- **알레르기·맵기**는 필터 가능한 필드로. 알레르기 표기는 "대체 가능" 여부까지.
- 이미지 파일명 = `img` 값. 사진 없으면 자리 배경색으로 폴백.

## 3. 화면 구성

```
진입(2~3초, 건너뛰기·4초 강제·reduced-motion 생략)
→ 히어로: 가게 사진 + 손님의 질문 한 문장 + 영업 중/마감 상태
→ (선택) 센터피스: 핀 스크롤로 대표 메뉴가 만들어지는 과정
→ 이번 주/오늘 한정
→ 메뉴: 스티키 분류 탭(현재 섹션 따라 활성) + 검색 + 태그 칩 → 항목 → 상세 시트
→ 주문 도구 (가게마다 다름)
→ 영업시간 · 위치 · 예약/웨이팅 · 전화
→ 푸터 "디자인 예시용 가상 가게 · 사진 AI 생성"
```
- 폰 한 손: 탭·칩은 높이 44px 이상, 상세는 아래에서 올라오는 시트(Escape·바깥 탭·아래로 끌기로 닫힘, 포커스 가둠).
- 주문 도구가 금액을 계산하면 **근거를 같이 보인다**(1인 기준 g, 세트 할인 조건).
- 실제 주문 연동이 없으면 "직원에게 이 화면을 보여주세요" 주문서 화면으로 마무리한다.
- 영업 상태는 요일·시간 데이터(`OPEN`)로 계산해 "지금 영업 중 · 22시 마감"처럼 보인다.

## 4. 사장님이 직접 고치는 버전 (선택)

손님 화면은 그대로 두고:
- 메뉴 데이터를 DB 표(`categories`, `items`)로 옮기고, 페이지는 공개 키로 읽기만 한다. 쓰기는 로그인한 사장님만(RLS).
- DB가 멈췄을 때를 위해 `menu-backup.js`(마지막 메뉴 사본)로 폴백.
- 관리자 화면: 품절 토글·가격 수정·순서 변경을 폰에서 한 손으로.
- **공개 키만 페이지에** 넣는다. service_role/secret 키가 페이지에 들어가면 누구나 메뉴를 바꿀 수 있다 → 들어갔으면 즉시 폐기.
- QR은 가게 URL로 만들고 A6 인쇄 카드로.

## 5. 디자인 기준

- 배경 순백·순검정 금지, 강조색 1개(면적 10~40% 블록 2곳 이상).
- 본문 14~15px, 가격은 tabular-nums. 한글 제목 700~800·자간 −0.01~−0.02em. radius 한 계열.
- 영문 모노 대문자 라벨·섹션 번호 금지(예시의 Address·Shot 같은 영문 라벨은 규칙 이전 제작분 — 새 가게는 한글).
- 이펙트는 진입 또는 센터피스 하나 + 주문 도구의 작은 반응 하나. 메뉴 목록은 정적이고 빠르게.
- `prefers-reduced-motion`에서 모션 끔.

## 6. 검증 — 안 봤으면 완료라고 하지 않는다

```bash
node <스킬>/scripts/verify.mjs http://127.0.0.1:8765/<폴더>/ <출력폴더>
```
320·390·430·1440 폭에서 진입이 스스로 걷히는지, 가로넘침·콘솔 오류, 메뉴 첫 항목 탭 → 상세 시트가 열리고 Escape로 닫히는지 보고, 스크린샷을 직접 연다. 주문 도구는 수치 경계(0명·최대 인원·세트 조건 경계)를 손으로 한 번씩 눌러 본다.
